# StudyOS 设计说明

## 1. 设计方向

StudyOS 面向长期积累的学习记录。界面借鉴 Linear 的清晰任务结构、Notion 的编辑节奏和 GitHub 的连续贡献视图，但使用自己的蓝紫色控制色与学科色标识，不复刻品牌组件。

**视觉锚点：** 今日工作台把“今天投入了什么”作为第一视觉焦点：一条精简的时间总览与本日节奏，不用虚构的增长数字或大面积渐变。内容面向左对齐，阅读顺序从今日摘要到待办、分类投入，再到最近活动。

## 2. 设计令牌

### 色彩

| 令牌 | 浅色 | 深色用途 |
| --- | --- | --- |
| 主色 | `#4F46E5` | `#818CF8`；主要操作、当前导航 |
| AI | `#8B5CF6` | `#A78BFA`；AI 分类 |
| Java | `#F59E0B` | `#FBBF24`；Java 分类 |
| 科研 | `#0D9488` | `#2DD4BF`；科研分类 |
| 页面底色 | `#F8FAFC` | `#0B1220` |
| 内容表面 | `#FFFFFF` | `#111B2B` |
| 主文字 | `#172033` | `#E5EAF3` |
| 次文字 | `#667085` | `#A5B0C2` |
| 边界 | `#E2E8F0` | `#273449` |

状态色使用满足对比度的语义色。分类色只用于图标、短标签和图表，不染整张卡片。危险操作使用明确的红色，不用分类色表达状态。

### 字体与排版

- 中文优先系统字体：`Inter`, `-apple-system`, `BlinkMacSystemFont`, `"Segoe UI"`, `"PingFang SC"`, `"Microsoft YaHei"`, sans-serif。
- 正文 14–16px，行高 1.55；页面标题 24–28px；卡片标题 15–16px；统计数字只在确有数据时强调。
- 说明文字控制在约 70 个字符以内，避免孤立的装饰性大写眉题。

### 尺寸

- 侧栏宽 248px（收起 72px）；顶栏 64px；内容最大宽度 1440px。
- 主内容间距 24px，移动端 16px；面板边角 12px，输入与按钮 8–10px。
- 使用细边框与轻微表面层次，不为每张卡片添加相同阴影。
- 页面和列表支持流式网格：宽屏 12 栏，中屏 8 栏，手机 1 栏。

## 3. 页面布局

### 桌面工作台

```text
┌──────────────┬───────────────────────────────────────────────────┐
│ StudyOS      │ 今日工作台                         日期 / 记录活动 │
│ 工作台       ├───────────────────────────────────────────────────┤
│ 任务         │ 今日时长         完成任务        连续学习            │
│ 学习日志     ├─────────────────────────┬─────────────────────────┤
│ 项目中心     │ 今日待办                │ 分类投入与周目标        │
│ 数据统计     ├─────────────────────────┴─────────────────────────┤
│              │ 最近学习记录                                      │
│ 设置 / 用户  │                                                   │
└──────────────┴───────────────────────────────────────────────────┘
```

侧栏只承载一级导航；顶栏放页面标题、快速记活动与账户操作。数据卡片按优先级混合宽度，活动列表在桌面显示日期、分类和时长。

### 手机工作台

```text
┌──────────────────────────┐
│ StudyOS       头像 / 新建 │
├──────────────────────────┤
│ 今日工作台                │
│ 今日时长 / 任务 / 连续天数│
│ 今日待办                  │
│ 分类投入                  │
│ 最近活动                  │
├──────────────────────────┤
│ 工作台 任务 日志 项目 统计│
└──────────────────────────┘
```

所有移动内容单列展示。快速记录从顶栏或日志页固定操作触达；底部导航遵守 `env(safe-area-inset-bottom)`，表单末尾留出键盘和导航空间。

## 4. 交互约定

- 保存动作使用明确动词，如“保存任务”“记录活动”；成功提示沿用相同语义，如“活动已记录”。
- 异步区块各自显示轻量骨架；网络错误显示重试；空状态解释下一步并提供真实可用入口。
- 任务看板允许显式拖拽或状态菜单更新状态；保存服务仅更新状态和更新时间。
- 删除确认展示对象名称；写入期间禁用按钮，失败不清空用户输入。
- 日期编辑器始终呈现用户时区日期；不通过午夜 UTC 转换导致日期漂移。
- 深色主题通过 CSS 变量切换，初次从系统偏好读取并在用户设置中持久化。

## 5. 图表

- 热力图按周列、星期行显示，日期格式与用户时区一致，键盘聚焦时显示日期和分钟数。
- 趋势图支持 7 / 30 / 90 天切换；分类占比与每周时长共用学科颜色。
- 图表只渲染查询返回值；无记录时显示带入口的空状态，不显示零值之外的示例点。
- 所有图表容器在手机设定最小高度，ECharts resize 跟随容器宽度。

## 6. 状态与反馈

| 状态 | 表现 |
| --- | --- |
| Loading | 与内容轮廓接近的骨架，不闪烁虚假数值 |
| Empty | 一句解释、真实的“新增”动作和可选帮助链接 |
| Error | 说明读/写失败，保留填写内容，给“重试”动作 |
| Success | 页面内短暂 toast 或保存标记，可继续操作 |
| 未配置 | 登录页显示管理员配置提示；不提供可绕过认证的演示模式 |
| 过期任务 | 截止日期和“已逾期”标签清楚呈现，不自动更改状态 |
